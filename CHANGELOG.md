# Changelog

## [v1.0.0] - 2025-03-23

### Added

- Регистрация и логин пользователей (JWT)
- Базовая структура проекта (backend + frontend)
- Интеграционные тесты для авторизации
- Очистка текста, история заданий
- Дашборд с графиками
- Уведомления
- Экспорт истории в CSV
- Документация по проекту
- Удаление скрытых меток GPT: очистка текста от невидимых Unicode-символов (форматирующие Cf, управляющие C0/C1, схлопывание неразрывных пробелов). Миграция для существующей БД: `backend/src/config/migrations/2026-09-remove_hidden_markers.sql`.
- Очистка текста заменяет все тире (hyphen, non-breaking hyphen, figure dash, en dash, em dash, horizontal bar — U+2010–U+2015 и minus sign U+2212) на обычный дефис `-`.
- Версия ключа кэша Redis повышена до `clean:v2:<sha256>`, чтобы не отдавать результаты, очищенные до этого изменения.
